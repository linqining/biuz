## 4. 必须继承的架构决定（改这些之前先读理由）

1. **调色板快照**（Android `ui/theme/Color.kt`）：`val BiuZ*` 是读 `BiuZColors.current` 的 getter，`BiuZTheme` 组合前写入档位。
   → 新增颜色请加进 `BiuZPalette` + 两个档位 + getter，**不要**再写硬编码 `Color(0x…)`（否则浅色档必花）。
2. **Markdown 三端同口径**：iOS `TinyMarkdown` / Android `MarkdownParser+MarkdownText` / 小程序 `chat-model.parseBlocks+parseInline`。
   块集与容错必须同步（未闭合围栏按代码块、表格缺分隔行降级段落、未闭合行内标记按字面量）；**改动一处要同步另两处 + 各自单测**。
3. **per-turn ≠ 任务级**（P-019）：web 的变更摘要属于「该轮助手消息」，数据源是 `turnHeader` 行；**不要**退回任务级常驻条。
4. **能力清单只读**：记忆/技能/MCP/插件四页一律无写面（启停/卸载/安装不接），移动端越界即失守。
5. **失败契约不统一是坑**：`setArchived` 失败**不抛异常**（回滚 + `lastArchiveFailureText()`）；`loadCapability` 抛 `CapabilityError`。
   调用新 store 方法前先读它的失败约定，否则「点了没反应」。
6. **空态必须能区分原因**：未连接 / 索引未就绪（+重试）/ 真无数据 —— 三态不可合并（合并即误导，见 `b5e79e2`）。
7. **安全区**：所有新页面根容器要 `.statusBarsPadding()`（本轮四屏漏过，已被用户当面指出过一次）。
