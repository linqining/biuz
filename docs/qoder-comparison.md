## 屏 2：执行目标选择器 + Composer（会话输入区）

用户截图要点（23:21）：

1. **执行目标选择器**：composer 上方的紧凑弹出菜单，两项——`☁️ 云端`（云端沙盒执行）与 `✓ ◎ Qoder CN`（本机执行，✓ 为当前选中）。**目标选择发生在 composer 级**，一键切换"这条消息发到哪执行"，而非表单里填 host/token。这正是"手机发命令、电脑/云端执行"的产品化表达。
2. **Composer 结构**：`输入或按住说话`（文本+语音长按）｜ `+`（附件）｜ `▶`（执行/历史）｜ `Auto`（模型档位内联选择）｜ 麦克风 ｜ 黑色圆形 waveform 按钮（语音模式）。
3. 左上 `☰` 汉堡菜单（会话抽屉），浅色主题。

## 屏 3：执行目标选择器展开态（选中具体机器）

用户截图要点（23:21，与屏 2 同一会话）：

1. **当前目标内联常驻**：composer 上方显示 `◎ Qoder CN ⇕`（图标+名称+上下选择箭头）——目标始终可见，单击即换。
2. **选择器列出具体机器**：弹出菜单 `✓ 💻 MacBook-Pro-8.local`（笔记本图标 + ✓ 选中标记）——粒度是**具体设备**而非应用身份。
3. 背景可见项目文件夹（`📁 海盗…`）——会话归属项目分组贯穿列表与新建流程。

### 对 BiuZ 的落地映射（并入屏 2 的 P0 项）

- composer 上方常驻目标胶囊：`☁️ 云端沙盒` 或 `💻 MacBook-Pro-8.local`（取设备名），点击弹菜单；
- 菜单列出设备清单（云端沙盒固定一项 + 已配对 Mac 按机器名逐项），✓ 标当前；
- 切换后立即改变该 composer 的发送目标，下次冷启动沿用选中。

## 屏 4：三层上下文选择器（决定性交互）

用户截图要点（23:21，composer 上方三行常驻胶囊，各自带 ⇕ 切换箭头）：

1. `◎ Qoder CN ⇕` —— 账号/应用层
2. `💻 MacBook-Pro-8.local ⇕` —— 执行机器层
3. `📁 海盗老虎机 ⇕` —— **项目文件夹层**

三层独立可选、点击各自弹出候选；新建会话的"项目"不是表单字段，而是**常驻上下文胶囊**——切换项目后直接输入即可，会话归属随上下文走。下方 composer：输入/按住说话 + `+` 附件 + `▶` + `Auto` 模型档位 + 麦克风 + 语音模式按钮。

### 对 BiuZ 的落地映射（升级"新建会话选项目"的实现方式）

- **P0·三层上下文胶囊**：登录直达会话（屏 2 的目标选择器）升级为三层：账号（固定 Zai）/ 机器（云端沙盒 + 已配对 Mac）/ 项目（server-info workspaces + 历史会话去重的项目清单），三颗胶囊常驻会话页顶部或 NewConversationSheet 顶部，各自 ⇕ 弹出候选。
- 项目胶囊数据源与优先级：server-info workspaces → 历史会话去重项目名 → "新建项目"兜底；默认上次使用。
- 选择持久化：机器 × 项目组合记住，冷启动恢复上次上下文。
