盖章动效 · 规格表

印随批准权走：落印只发生在回执权威成功之后，绝不延迟命令下发。 批准落朱印「照办」，拒绝落墨印「不准」，失败与未送达不落印——错误行如实上屏（U-5 口径）。

规格

一段落印，两拍离场

落印总时长460ms
落印路径scale 1.6 → 0.96 → 1.04 → 1.0

印泥外溢外圈 520ms · 延迟 180ms（墨印同步墨色）
停驻700ms（印留住，卡不撤）
离场180ms · opacity + scale(.96)
触觉沿用既有 success/error 通知触觉，落印即触发
减弱动态全部停用 · 印以终态直出 · 停驻缩短
点击 · deciding ACK 真实延迟 落印 460ms 停驻 700ms 离场 180
按钮禁用 等待回执 印落 · 触觉 卡不撤 · 等对账 收卡

离场后卡片位置由「已收卡」占位行接管并复位；桌面 pendingInteractions 投影回流与本地停驻互不等待，停驻期满即收。

状态机

ACK 之后分三路

权威成功

  1. 落印：照办 朱印 + success 触觉
  2. 停驻 700ms，卡面保持可读
  3. 离场 180ms；本地停驻期 ≠ 等投影
  4. 投影回流对账：缺席即永久收卡

拒绝（权威成功）

  1. 落印：不准 墨印 + 标题划除
  2. 同款停驻 / 离场 / 对账
  3. 外溢圈同步墨色，不共用朱色

失败 / 未送达

  1. 不落印 —— 印是权威成功专属
  2. reasonCode + message 原文上屏错误行
  3. 按钮即刻恢复，可重发
  4. 卡片保持在场（U-5 口径）
