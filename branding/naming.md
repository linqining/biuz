# BiuZ · 品牌命名与商标避险报告

> 2026-10-02 · 配套 Logo 见 [branding/logo/](logo/)（SVG 源稿 + PNG 渲染）
> 背景：本项目是 ZCode 的社区版 iOS 客户端。「ZCode」是 z.ai 的产品商标，直接以「ZCode」上架 App Store 会触发商标侵权与审核风险（苹果审核对「模仿/混淆其他品牌」有专门条款）；且「Xcode」为 Apple 注册商标，任何「××Code」式命名都应避开。上架前必须完成更名。

---

## 结论（先读）

**推荐定名：BiuZ**（App Store 显示名 `BiuZ`；中文语境可读作「必优 Z」或直接读「biu~Z」）。

- 这是立项人自提的候选名，经检索核验后**在软件/应用领域未发现任何占用**，是全部候选中唯一干净的名字。
- 「biu~」是中文互联网通用的拟声词（发射、疾飞）——**把任务 biu 地一下发给 Agent**，正好是本产品「手机遥控下发任务」的核心动作；4 个字母、朗朗上口，符合 TRAE / Qoder 式的短 coined 名惯例。
- 结尾的「Z」保留了对 ZCode 社区版血统的辨识度，但整体商标在**字形、读音、含义**上与「ZCode」均不近似，不构成混淆性近似。⚠ 注意：商店名称/副标题/截图/关键词中**不得出现**「ZCode」「Z.ai」字样或其 logo——社区版身份靠「works with ZCode」式描述性文字表达（如「BiuZ — remote console for your coding agents」），不做品牌联动暗示。
- 相比之下 **BiuAI 不建议用**：已存在 [biu.ai 公司](https://www.cbinsights.com/company/biuai)（AI 保险销售工具），域名 biu.ai 与「BiuAI」视觉混淆度高，同属 AI 软件类目；且「AI」后缀通用词弱化商标显著性。

## Logo 交付物（[branding/logo/](logo/)）

设计概念：**「biu~」彗星**——一道拖着渐细尾迹的荧光绿流星划出一个「Z」，亮核是任务飞出时那颗「biu」的光点。配色完全沿用 design-spec v2.4 令牌：近黑底 `--bg #0a0b0d`、强调绿 `--accent #32f08c`（Light 版用 `#17b26a`）。

| 文件 | 用途 |
| --- | --- |
| `logo/biuz-icon-1024.svg` | App Store 提审图标源稿（方形全出血、无透明，圆角由系统裁切） |
| `logo/biuz-icon-rounded.svg` | 预览用圆角版（rx=228 ≈ iOS 裁切比例） |
| `logo/biuz-mark.svg` | 透明底单标（960×960 方形画布；替换 design/login-design.html 屏 01/O1 的 84px 品牌位，以及 README） |
| `logo/biuz-mark-card.svg` | 单标深色卡片版（README/宣传展示） |
| `logo/biuz-lockup-dark.svg` / `-light.svg` | 横版字标（深/浅主题，字标为纯矢量路径不依赖字体），含副标题「手机上的 AI Agent 遥控台」 |
| `logo/png/` | 全部渲染 PNG：`appicon-1024/180`、`icon-preview-512`、`lockup-dark/light`（1100×560）、`mark-960`（透明底）、`mark-card-840` |

设计说明：彗星「Z」即字标的字母 Z——尾迹沿 Z 笔顺由细渐粗，亮核是任务飞出时那颗「biu」的光点；字标中 i 的圆点同样做成绿色发光灯，与彗星亮核互为呼应。全部用色取自 design-spec v2.4 令牌（`--bg #0a0b0d`、`--text #f5f9fe`、`--text-3 #8a8f9b`、`--accent #32f08c`；Light 用 `#f4f5f7 / #17181c / #5f6673 / #17b26a`）。

### 上架合规清单（BiuZ 定名后的工程改动点）

1. App 显示名：`ZCode` → `BiuZ`（`ios/project.yml` 的 target 属性，重跑 `xcodegen generate`）。
2. Bundle ID：`cn.zcode.mobile` → `cn.biuz.mobile`（已定稿统一口径，自有域名反写；TestFlight/App Store Connect 需同名新建，旧 `cn.zcode.*` 记录不可复用。Keychain service 常量同步为 `cn.biuz.mobile`，切换前旧凭据对本 App 不可见——需重新登录与重新配对，工程未上架无外部存量用户，属预期一次性成本）。
3. App Store Connect：显示名 `BiuZ`、副标题可用「AI Agent 遥控与审批台」；**关键词/截图/描述中不出现 ZCode、Z.ai、Zai 字样与官方素材**。
4. 应用内第三方服务引用（如「使用 Z.ai 账号登录」）属功能性描述可保留；商店元数据不做品牌联动暗示。
5. 图标替换：`AppIcon` 资产用 `png/appicon-1024.png`；登录页 84px 品牌位用 `biuz-mark.svg` 对应的 PNG/PDF 切图。
6. 商标检索：中国商标网 9/42 类查「BiuZ」「Biu」家族（重点 biubiu 加速器近似判断），通过后再定提交。
